# 姑苏寻迹数据缺口

更新时间：2026-09-25

## 当前未满足的资料要求

1. 本地与公开版本均已切换为 OSM WGS84 九区边界（ODbL 1.0）；旧 DataV 文件不纳入 Git 和发布。
2. 350 个地点已达到“220 个核心＋130 个扩展”的结构规模，但大部分仅完成 OSM 基础核验，尚未完成官网或文旅部门的第二来源复核。
3. 64 个精简地点（`library=core` 且 `priority<=2`）均有独立概览、探索建议、看点、建议时长及到访提醒；其余 286 个地点仍待逐项整理。本次新查阅 10 个园林局景点页面及 6 个大学官方页面；不代表所有地点都完成官方复核。当前营业时段与票价统一标注尚未逐项核实。
4. 45 个精简地点已收录共 51 张有署名和许可证信息的本地实景照片，包括全部 12 处精简古典园林。其余 19 个精简地点缺少已核实照片，明确显示缺图状态，不以相似建筑、其他馆区或校区图片替代。
5. 摄影机位尚未完成“合法、安全、公开可达并有对应授权样片”的逐个核验。
6. 公交线路只保留数据接口和“无法可靠生成”降级逻辑，尚未建立与全部地点关联的公交网络。
7. 轨道交通已生成线路和站点顺序，但换乘站同名合并、运营变化和站点开放状态仍需官方资料复核。
8. 铁路连接尚未录入可靠的代表性运行时间，因此当前铁路方案会明确显示无法生成。
9. 驾车用时使用离线距离修正估算，不是完整道路图最短路径，也不包含实时路况。
10. 行政区代表图片尚未完成授权核验。
11. 地点主分类目前依据 OSM 标签、名称规则和少量重点地点人工校正生成；已修正乐园、海洋馆、植物园等明显误分，但全部350个地点仍需逐条人工复核，低信息量候选也需继续清退。

## 本次资料边界

- 7 个精简地点暂未接入可用的第二背景来源：平江路、苏州工艺美术博物馆、苏州摩天轮、国防科技大学外国语学院昆山校区、江苏巡抚衙门旧址、金门、苏帮菜博物馆西中市馆。仅保留谨慎的基础说明与参访提示，仍需进一步核实。中科大苏州机构补充了官网，但不代表仁爱路校园现状与开放已核实。
- 大学主条目可能仅提供学校背景，不能证明某个校区对外开放。苏州博物馆主条目不能代替西馆的专属资料或照片。
- 已排除百科接口跳转到 API 介绍页的无效研究记录，不将其展示为内容来源；原始研究缓存仅供审查，不能直接作为已核验正文。

## 处理原则

- 缺少可靠数据时明确显示“暂无经核验信息”或“当前离线数据无法生成可靠方案”。
- 不以模型生成内容代替事实资料。
- 不使用未经授权的社交平台图片。
- 不因验收目标而伪造地点、路线、价格、开放时间或来源。
